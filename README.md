# HR Data Analysis

## Description
The dataset encompasses a range of attributes concerning employees, from demographic details to job-related factors. The primary objective of this analysis is to forecast employee turnover and discern the underlying factors contributing to employee attrition.

## About the Dataset
The dataset contains various attributes, including:

- **Satisfaction Level**: The employee's satisfaction level on a scale.
- **Last Evaluation**: The score of the employee's last evaluation.
- **Number of Projects**: The total number of projects the employee has worked on.
- **Average Monthly Hours**: The average number of hours worked by the employee each month.
- **Time Spent in Company**: The total time (in years) the employee has spent in the company.
- **Work Accident**: A binary indicator of whether the employee has had a work accident.
- **Promotion in Last 5 Years**: A binary indicator of whether the employee has been promoted in the last five years.
- **Department**: The department in which the employee works.
- **Salary**: The salary level of the employee.


## Results
The analysis reveals key factors contributing to employee turnover and offers recommendations for improvement.
